# Colony Glorb

### Description du jeu

Colony Glorb est un jeu de réflexion et de tri par couleurs où vous dirigez une colonie d'aliens affamés chargés de dévorer des illustrations en pixel art (hmmmmmhhh 😋). Touchez les boites de couleurs pour envoyer vos aliens manger les blocs correspondants sur l´image, tout en gérant correctement les emplacements pour ne pas se bloquer.

## Installation et Compilation

Le projet utilise **Maven** pour la gestion des dépendances et la compilation.

### 1 - A partir du code source du jeu
Après avoir téléchargé le code source :

1. **Compiler le projet :**
   ```bash
   mvn clean package

2. **Lancer le jeu :**
    ```bash
   java -cp target/ColonyGlorb-1.0.jar

### 2 - Avec le fichier exécutable (plus simple)
1. **Se rendre sur la page des [releases](https://moule.informatique.u-paris.fr/abballab/projet-cpoo-5-2627-session-1-abballabalali-daimi/-/releases)**

2. **Télécharger le "Jeu exécutable"**

3. **Se rendre sur le répertoire du fichier .jar téléchargé et exécuter**
   ```bash
   java -jar ColonyGlorb-1.0.jar
